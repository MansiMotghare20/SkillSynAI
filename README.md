# SkillSynAI
AI-powered skill gap analysis and personalized learning roadmaps using resume parsing, NLP, and intelligent course recommendations.
**SkillSyncAI – AI-Based Skill Gap Analyzer and Personalized Learning Roadmap Generator**

SkillSyncAI is an AI-powered platform designed to help students and job seekers identify the skills they need to achieve their career goals. It analyzes uploaded resumes or manually entered skills, compares them with the requirements of a selected job role, and identifies missing skills.

The system uses Natural Language Processing (NLP) for skill extraction and AI-based techniques to generate personalized learning roadmaps. It also recommends relevant courses, tutorials, and other learning resources to help users improve their skills and prepare for industry requirements.

**Key Features:**
- User registration and login
- Resume upload and parsing
- Automatic skill extraction using NLP
- Manual skill entry
- Target job role selection
- Skill gap analysis
- AI-generated personalized learning roadmaps
- Learning resource and course recommendations
- Learning progress tracking

**Technology Stack:** React.js, JavaScript, Tailwind CSS, Node.js, Express.js, MongoDB, Python, Scikit-learn, and LLM API integration.

**Project Goal:** To bridge the gap between academic knowledge and industry requirements by providing students and job seekers with personalized, practical, and structured career development guidance.
